PiBank — Android Java project

Пакет: com.pibank.demo
Firebase project: pibank-af59b

Что обновлено в версии 1.1:
- Обновлён внешний вид виртуальной карты: тёмный фон, фиолетовый градиент и оформление vida.
- На лицевой стороне карты показываются баланс, номер, владелец и тип карты.
- Нажатие на карту переключает лицевую и обратную стороны.
- Добавлена версия приложения 1.1 (versionCode 2).

Что уже предусмотрено в проекте:
- Вход и регистрация через Firebase Authentication.
- Создание до трёх карт на пользователя: дебетовая, кредитная или детская.
- Генерация случайного 16-значного номера с проверкой уникальности через Realtime Database.
- Чтение балансов, новостей и истории из Firebase Realtime Database.

Важно:
- Это приложение не подключено к платёжной сети и не выпускает настоящие платёжные карты.
- Реальные операции, начисление средств и административные изменения требуют защищённого серверного API и правил Firebase.
- Перед публикацией настройте и проверьте правила Firebase Realtime Database.
- APK в этом архиве не содержится. Сборку выполняйте через GitHub Actions.
